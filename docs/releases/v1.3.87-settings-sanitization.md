# Codian 1.3.87 Settings Sanitization

This patch completes the provider cleanup by enforcing the current settings schema at both load and save time.

## Changes

- Unknown root settings are ignored instead of being written back.
- Provider configuration is limited to Codex and DeepSeek.
- Current user preferences, encrypted secrets, vault content, sessions, skills, commands, and agents remain untouched.

## Verification

- Build, type checking, linting, unit tests, integration tests, release packaging, and SHA-256 checks pass.
- Source files, filenames, production dependencies, bundles, release assets, installed settings keys, and installed program files are checked for retired provider markers.
