# Codian 1.3.86 Provider Cleanup

This release consolidates Codian on the Codex App Server, with DeepSeek remaining available as the optional API provider.

## Data safety

- Plugin-owned vault data now lives under `.codian/`.
- Migration uses a staged copy, content digest verification, an atomic destination rename, and a receipt.
- Symbolic links are preserved as links and are never traversed during migration.
- The installed plugin directory and the previous vault data root are backed up outside the active vault before replacement.

## Runtime cleanup

- Removed retired runtime adapters, dependencies, compatibility settings, plugin discovery, browser integration, and old model-tier behavior.
- CLI resolution now accepts only an actual `codex` or `codex.exe` file.
- Session history loading now reads only the Codex session index and Codian's own vault metadata.

## Verification

- Type checking, linting, unit tests, integration tests, release packaging, asset hashes, installation hashes, and live Obsidian startup are verified before release completion.
- A package policy test rejects retired provider markers in source files, filenames, dependency manifests, and the production bundle.
