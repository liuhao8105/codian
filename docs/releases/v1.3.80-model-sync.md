# v1.3.80-model-sync

## Overview

This release keeps Codian's model selector aligned with the models exposed by the installed Codex CLI and preserves the network-resilience fix from v1.3.79.

## Model Synchronization

- Reads the current account's visible models from the Codex App Server `model/list` method.
- Uses a five-second timeout so model discovery never blocks Obsidian startup.
- Falls back to the locally verified Codex CLI `0.144.5` catalog:
  - GPT-5.6-Sol
  - GPT-5.6-Terra
  - GPT-5.6-Luna
  - GPT-5.5
  - GPT-5.4
  - GPT-5.4-Mini
- Uses GPT-5.6-Sol as the default for new installations and internal Codex fallbacks.
- Preserves supported model selections and custom provider models.
- Migrates only retired GPT-5.2 and GPT-5.3-Codex selections to the CLI-reported default.
- Applies the default reasoning effort reported by the CLI when a built-in model is selected.

## Network Resilience

- Keeps retryable App Server disconnect messages hidden while the Codex CLI reconnects.
- Replaces an exhausted ChatGPT transport disconnect with a concise Chinese recovery message.

## Compatibility

- Codex CLI: `0.144.5` verified locally.
- Obsidian minimum version: `1.4.5`.
- No new dependencies, API keys, databases, servers, or Docker services.
