# v1.3.81-session-safety

## Overview

This release prevents Codian from resuming a Codex thread with a different model after the user changes the model selector. It also includes the model synchronization and network-resilience improvements from v1.3.80.

## Session Safety

- Clears only the resumable Codex session binding when the selected model changes.
- Preserves the existing Codian conversation and all visible chat messages.
- Rebuilds open-tab runtimes so the next message starts a fresh Codex thread with the newly selected model.
- Shows a concise notice explaining that chat history was preserved and the next message will use a new session.

## Model and Network Compatibility

- Uses the Codex App Server `model/list` catalog with a verified local fallback for Codex CLI `0.144.5`.
- Defaults new installations to GPT-5.6 Sol.
- Keeps retryable transport errors hidden during automatic retry and shows a concise recovery message only after retries are exhausted.

## Compatibility

- Codex CLI: `0.144.5` verified locally.
- Obsidian minimum version: `1.4.5`.
- No new dependencies, API keys, databases, servers, or Docker services.
